# Fluxora
### Creator Workspace

Aplikasi desktop untuk membantu fotografer mengelola karya, mengunggah foto ke FotoYu, dan memantau aktivitas dalam satu workspace.

## Unduh

[Unduh Fluxora versi terbaru](https://github.com/scriptzibecks/FLUXORA-PUBLIC/releases/latest)

Tersedia untuk **Windows x64**.

## Fitur

- Upload foto dengan pengaturan publikasi dan metadata EXIF.
- Pemantauan progres dan kecepatan upload.
- Riwayat sesi serta batch unggahan.
- Galeri Analisis FotoYu.
- Pemeriksaan update langsung dari aplikasi.

## Mulai menggunakan

1. Unduh installer melalui halaman Releases.
2. Instal dan buka Fluxora.
3. Aktifkan menggunakan lisensi Fluxora.
4. Masuk dengan akun FotoYu kamu.

## Pembaruan

Fluxora memberi tahu ketika versi baru tersedia. Buka
**Pengaturan → Pembaruan Aplikasi → Cek update**
untuk mengunduh pembaruan.

Restart aplikasi dilakukan setelah konfirmasi pengguna.
